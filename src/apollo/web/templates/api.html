Read resources

GET /api/v1/status reports configuration and worker availability. List playlists, ratings, votes, skips, or jobs under /api/v1/. Lists accept limit=50&offset=0 (maximum limit: 200).

GET /api/v1/song?song=Artist%20-%20Title returns every matching Elasticsearch entry, selection reasons, the current winner and a rating summary. Submit entry.play with an entry_id to play a specific file.

Submit an operation

POST /api/v1/jobs
Content-Type: application/json
Authorization: Bearer YOUR_TOKEN

{"action":"playlist.preview","payload":{"type":"artist","input":"New Order","name":"night-drive"}}

A successful submission returns 202, a job, a status_url, and a Location header. Poll the status URL for queued, running, succeeded, partial, or failed status. Results, errors and recent progress messages are included.

Restart

POST /api/v1/restart
Authorization: Bearer YOUR_TOKEN

The response is sent before Apollo exits. This endpoint requires bearer authentication and assumes a service supervisor will restart Apollo.

Access

Configure APOLLO_API_TOKEN or API_TOKEN for bearer access and browser login. Browser POST requests require a session CSRF token in X-CSRF-Token or csrf_token. A valid bearer token authenticates API requests without a browser session.

Complete field rules and examples are in docs/api.md.
